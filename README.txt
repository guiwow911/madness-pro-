暴力迪吧联合计划 · 网页局域网测试包
====================================

快速启动
--------
1. 电脑安装 Node.js 18 或更新版本。
2. 双击 start.bat（不受 PowerShell 执行策略影响），或在此目录运行：
     node server.js
3. 终端会显示本机地址。主机浏览器打开 http://localhost:8787。
4. 同一 Wi-Fi / 局域网的另一台设备打开终端显示的 http://局域网IP:8787。
5. 两边选择相同房间代码，填不同玩家名，并分别选择主武器/副武器；房主看到 2 / 2 后点击“开始多人竞技场”。
6. 双开测试可在同一电脑的另一个浏览器窗口再次打开 http://localhost:8787。
7. 两个窗口的游戏启动页各点击一次 LAUNCH；之后会自动进入竞技场，在角色页点“完成”后直接进入 PVP 地图。

依赖与本地验证
--------------
- Ruffle 网页运行时已随包放在 public/ruffle，无需 CDN；游戏在 public/game.swf。
- Node 依赖已放在 node_modules。重新下载/解压后需要运行 npm install。
- npm test 会启动临时本地服务，验证 SWF/Ruffle 静态资源、两人进房、PVP 开局、角色状态与命中事件转发、离房事件。
- 本测试版为 1v1 PVP：每人自行选择两把武器；竞技场使用单间地图、不触发普通敌人波次；玩家子弹/近战命中会通过房间转发给对手并应用在对手本机角色上。
- 每个房间最多 2 人；远端同步角色位置、朝向、动作状态、双方自选武器与当前持枪槽，并在本地帧率下插值补帧；不会注入远端按键到本机控制。
- 退出本局 / 返回大厅会刷新此页并重新加载游戏。

网络结构
--------
浏览器中的 Ruffle 运行修改后的 SWF；ActionScript 通过 ExternalInterface 把状态交给同页 JavaScript，JavaScript 使用 WebSocket 连接本机 Node 房间转发器。服务器只转发同一房间另一位玩家的数据。

原始 SWF 保持不变。此测试版本沿用用户提供的游戏资源，仅生成独立网页包和测试 SWF。
